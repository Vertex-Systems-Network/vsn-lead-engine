# Bounded source-aware CSV preparation and accounting

Adds an authenticated CSRF-protected POST at `/api/v1/workspaces/<workspace>/jobs/<job>/exports/`. GET does not prepare or charge. Current owner/admin/member membership is required; viewers and foreign/revoked users cannot export. JSON selects 1–25 unique result UUIDs and 1–6 allowlisted fields, with a separate bounded Idempotency-Key header. IDs/fields are canonicalized; unknown input/query parameters are denied. Every selected record and requested field must remain available; no silent partial export or automatic field omission occurs. A future preview must explain omitted/disallowed fields and require explicit corrected selection before this API is invoked.

Reuse the repository's pure `authorize_export` policy contract from the trusted repository `src` path; no collector/provider services are imported. Existing read checks revalidate saved source fingerprint, rights, scope, field lineage and deadlines. A separate source `controls.export_contract` must already be part of the saved source fingerprint: exact version=1, allowed=true, allowlisted fields, matching purpose/retention_version and bounded nonblank attribution. Display/storage permission cannot grant export. Source rights changes invalidate the saved operation; there is no retroactive grant. All source policies/signers remain disabled/unconfigured by default.

One export usage unit is one successfully prepared CSV of at most 25 rows, not a delivered-file acknowledgement or row credit. Workspace locks, existing atomic reserve/settle/cap services, outstanding reservations and active accounting windows guard new preparation. A redacted protected ResultExport stores actor, workspace/job, key/request hash, keyed output digest, quantity, earliest expiry and reservation. It stores no CSV, row IDs/field values, source record refs, signatures or signed download URLs. Same actor/key/specification replays current eligible identical bytes without another charge; changed request/content conflicts. Current role/rights/active entitlement/expiry are checked on every replay. SECRET_KEY rotation invalidates the keyed replay comparison safely.

CSV is built in memory, quoted structurally, UTF-8 and capped at 128 KiB. Formula-like values beginning with =,+,-,@ after whitespace are prefixed with an apostrophe, including +phone values. Source/policy, observation/deadline, retention version and required attribution accompany selected fields. Responses are private/no-store, attachment-only and nosniff; the receipt UUID is not download authority. A response failure after preparation can replay while rights/deadlines permit. No server-stored export copy or unprotected GET download exists. Downloaded client copies cannot be recalled; delivery after response authorization cannot be controlled by this transaction.
