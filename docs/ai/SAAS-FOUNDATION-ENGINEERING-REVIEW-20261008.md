# SaaS foundation engineering review — 2026-10-08 PKT

Scope: merged PRs #154–#157 and the isolated quality-baseline change. This is workspace engineering review and automated behavior evidence, not independent human review or production certification.

- Architecture: the Django project, lock and migrations live under apps/saas; existing collector entry points, runtime lock, Google delivery and R2 ledger are unchanged. No app request dispatches a provider, creates a billing charge or claims delivered leads.
- Authorization: queries first scope to server-resolved membership and workspace. Foreign/missing resources return 404; viewers cannot write. Mutations re-resolve/lock membership within the workspace transaction. Last-owner changes serialize on the workspace and preserve at least one owner; admins cannot promote/change ownership.
- Integrity: normalized draft requests and reservation quantities are hashed server-side. Unique tenant/key constraints, workspace locks and repeat/conflict tests protect duplicate creates. Settled usage is idempotent and cannot exceed reservation or be refunded through release. Internal entitlement/settlement services have no client-authoritative API.
- Security: CSRF-protected Django sessions, POST logout, secure non-debug cookies/HTTPS/HSTS and required secret configuration. Login account/IP counters serialize on PostgreSQL, normalize Unicode names, ignore forwarded address selection and retain keyed fingerprints. Production abuse/proxy/recovery review and periodic cleanup remain open.
- Tests: existing product suite 332 passed locally. PostgreSQL CI on #154–#157 verifies cross-tenant/role/CSRF/validation/idempotency behavior, duplicate-create concurrency, concurrent last-owner demotion, concurrent login budgets, concurrent usage caps, migration forward/back/forward and production-settings checks. Local SQLite skips these four concurrency tests explicitly.
- Maintainability: domain services separate from serializers/routes; explicit bounded input/list sizes; current migrations checked against model drift. The isolated quality baseline adds pinned Ruff formatting/static/import checks and compilation without changing collector tooling. No assertion-mirroring tests were substituted for negative/concurrent behavioral checks.
- Open boundaries: job/outbox/lease/recovery, reservation expiry and billing-period policy, signed billing reconciliation, provider rights/activation, complete web UX/accessibility, deployment/restore/observability and external customer/privacy/launch evidence. Foundation remains in progress.
